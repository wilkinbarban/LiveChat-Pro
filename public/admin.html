Configuración del prompt del sistema para orientar el comportamiento e identidad del bot.

Guía de Variables Disponibles

Puedes usar las siguientes variables en tu prompt para inyección dinámica en tiempo de ejecución:

  • {visitor_name}: Nombre del visitante actual
  • {site_title}: Título del sitio web
  • {current_language}: Código de idioma del cliente
  • {rag_context}: Fragmentos de conocimiento RAG

Resumen de Matriz de Respuestas

El bot responde directamente en el idioma del visitante, prioriza hechos del contexto RAG y ofrece escalar a un agente humano si la confianza es baja o la información es incierta.
